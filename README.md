# PNTicket — Đặt vé xe khách online cho Nhà xe Phong Nhung

Web app giúp khách đặt vé xe giường nằm online (chọn ghế, chuyển khoản VietQR, nhận vé qua Email/SMS/Zalo) và giúp nhà xe quản lý vé, chuyến xe, tiền cọc được đối soát tự động — đặc biệt trong mùa cao điểm Lễ, Tết.
